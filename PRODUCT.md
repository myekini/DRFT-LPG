# DRFT

## Platform
web

## Stack
User-specified Next.js 15 App Router, TypeScript, Tailwind CSS v4, Geist, Instrument Serif, Lucide, Supabase and Plausible.

## Product purpose
Capture early-access email signups for an AI resume editor. The supplied brief describes targeted edits, user approval, voice preservation, resume memory and saved application versions.

## Constraints
One scroll, one conversion goal. No imagery or animation libraries. Preserve the supplied copy and design direction. Credentials, live signup count and Twitter/contact destinations are open configuration items.
